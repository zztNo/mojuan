常见问题

卡住了看这里。

Q：命令粘进去，屏幕上什么都没出现？
分两种：
· git remote add ... —— 成功就是不吭声，别慌，用 git remote -v 验证。
· git push 也完全没动静 —— 大概率在等登录窗口（它可能弹在别的窗口后面）。看看任务栏有没有新的登录窗口；或按 Ctrl + C 取消，然后先跑一次 git config --global credential.helper manager 再 push。
· 还有一种：把三行一次全粘进去，终端只执行了第一行。请改成一条一条粘。
Q：提示 remote origin already exists？
说明之前加过远程。直接用上面的命令（已含 git remote remove origin 自动处理），或手动执行：
git remote set-url origin https://github.com/zztNo/mojuan.git 再 push。
Q：提示 Authentication failed / 403？
密码那栏填的是令牌，不是登录密码；且令牌必须勾了 repo 权限。重新生成一个试试。
Q：提示 could not resolve host github.com？
检查网络 / 是否开了代理。换个网络再 push。
Q：想改提交显示的名字和邮箱？
推送前先执行：git config --global user.name "你的名字" 和 git config --global user.email "你的邮箱"。已存在的两条提交作者不会自动变，不纠结也行。
